# Liberation Sans Regular 2.1.5

Unmodified `LiberationSans-Regular.ttf`, embedded as the only UI face.
Liberation Sans provides Arial-compatible metrics. No font lookup or external
runtime font file is needed. Latin, Greek, Cyrillic and Hebrew are supported;
Arabic, CJK and emoji do not have full glyph coverage. UTF-8 transport and
whole-grapheme editing are independent of glyph coverage.

- Binary provenance: Debian `fonts-liberation_2.1.5-3_all.deb`,
