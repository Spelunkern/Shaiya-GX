# Liberation Sans Regular 2.1.5

Unmodified `LiberationSans-Regular.ttf`, retained as a source/test font reference.
Liberation Sans provides Arial-compatible metrics. The game now reads its UI and Unicode faces from external `data/fonts/` resources. Latin, Greek, Cyrillic and Hebrew are supported;
Arabic, CJK and emoji do not have full glyph coverage. UTF-8 transport and
whole-grapheme editing are independent of glyph coverage.

- Upstream: https://github.com/liberationfonts/liberation-fonts/tree/2.1.5
- License: SIL Open Font License 1.1, see `LiberationSans-OFL.txt`.
- Binary provenance: Debian `fonts-liberation_2.1.5-3_all.deb`,
  https://deb.debian.org/debian/pool/main/f/fonts-liberation/
- The unmodified font binary is retained for source tests; it is not embedded in the game.
