# External Unicode fallback fonts

Unmodified Noto regular fonts and Noto Color Emoji, loaded on demand without
OS font installation or network downloads. Every supplied Noto font identifies
the SIL Open Font License 1.1 in its embedded metadata. Preserve LICENSE-OFL.txt,
COPYRIGHTS.txt, LICENSE-CJK.txt and LICENSE-Emoji.txt. LICENSE-Noto.txt is the
original local package's Apache notice, retained for provenance; it does not
replace each font's own license.

Noto CJK SC Regular is the unmodified Sans/OTF/SimplifiedChinese/
NotoSansCJKsc-Regular.otf from https://github.com/notofonts/noto-cjk.
Other upstreams: https://github.com/notofonts and
https://github.com/googlefonts/noto-emoji.

No proprietary Arial or Microsoft Tahoma fonts are included.
